# OpenSim Procedural World

AutoPlant251.lsl erstellt inworld einen kompletten Wald zum betrieb müssen Texturen Materialien und Mesh Objekte vorhanden und eingefügt werden.

Wie AutoPlant251.lsl arbeitet

Das Skript:

    wählt zufällig Mesh‑Objekte aus deinem Inventar

    setzt sie an zufällige Positionen

    skaliert sie

    rotiert sie

    prüft ggf. die Höhe (z. B. kein Pflanzen unter Wasser)

Es ist also kein vollständiges Procedural‑System, sondern ein Inworld‑Rezzer, der vorhandene Assets nutzt.
